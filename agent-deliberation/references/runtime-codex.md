# Codex 运行时适配

仅在主文件选择独立 Subagent 执行时读取；单 Agent 方式不创建工作 Agent。

## 分配与启动

1. 按任务范围创建具名工作 Agent，提供分析目标、必要材料、约束和 [分析协议](analysis-protocol.md)。主 Agent 负责综合，工作 Agent 负责有边界的分析或复核。
2. 同题比较使用不继承主对话的隔离上下文，不发送其他答案或预期结论；互补任务按依赖和范围提供必要背景。
3. 明确工作 Agent 不编辑文件、不创建其他 Agent、不直接发布全局结果。
4. 保存 Agent ID 或任务名，需要复核时优先跟进同一 Agent。

## 调度与跟进

- 根据宿主实际并发容量分批调度，主 Agent 自身可能占用槽位。同题比较的后续批次不得继承先返回的答案。
- 任务有依赖时等待输入就绪再启动；独立任务可以并行。
- 空闲 Agent 使用可触发后续工作的跟进机制，运行中只发送必要补充。
- 收齐本阶段必要结果后综合，不因为最先返回的结果看似完整就省略已分配的分析。
- 复核传递具体判断和依据原文以及明确问题，无需完整对话。工作 Agent 之间的需求由主 Agent 中转。

## 失败与结束

创建因容量不足失败时缩小批次。单个任务失败可恢复或重试一次，仍失败则标记缺失，说明对结论的影响，不代写返回结果。

无法恢复上下文时，依据原任务与必要结果重建并说明。独立能力整体不可用时按主文件决定披露后降级或停止。

完成综合和必要的保存后释放工作 Agent；关闭失败不应丢失已完成成果。
