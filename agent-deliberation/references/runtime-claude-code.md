# Claude Code 运行时适配

仅在主文件选择独立 Subagent 执行时读取；单 Agent 方式不创建工作 Agent。

## 分配与启动

1. 主 Claude 会话负责任务拆分和最终综合，为独立分析创建具名 Subagent，可按宿主能力后台并行。
2. 提供分析目标、相关材料、约束和 [分析协议](analysis-protocol.md)，明确范围以及禁止修改文件、嵌套创建 Agent 和直接发布全局结果。
3. 同题比较使用全新隔离上下文，不传入其他答案或主会话预期结论；互补分析按依赖提供背景，不重复分配同一工作。
4. 保存可恢复的 Agent ID，需要复核时优先恢复原 Agent，发送待检查判断与依据原文和具体问题。

## 调度与收集

按宿主并发容量安排任务，不把累计创建额度当作建议数量。分批同题比较时保持初始材料一致，不泄露前批答案。有依赖的分析顺序执行。

优先使用完成通知收集结果，收齐当前综合所需的分析后判断下一步。工作 Agent 的补充需求经主会话处理，不直接联系其他工作 Agent。

## 失败与结束

单个任务失败时恢复或重试一次，仍失败则记录缺失及影响，不代写结果。上下文无法恢复时，依据原任务与必要结果重建并说明。

独立能力不可用时按主文件决定披露后降级或停止。完成最终交付和必要的保存后释放工作 Agent；关闭失败不影响已完成成果。
