# 设计原则

## 工作原则

- **结果先于分工**：先确定用户要解决什么，再选择独立比较或互补分析，不按固定角色与人数组织任务。
- **独立性有边界**：同题比较先隔离答案，互补任务避免重复劳动。多个 Agent 的推理仍可能相关，不能消除同一模型的系统性偏差。
- **依据支持判断**：共识、事实与价值选择分开；关键未知不能靠交换更多观点补足。
- **检查具体判断**：传递被检查内容和依据原文，问题聚焦于可能改变结果的矛盾、反例或遗漏，不强迫反对。
- **修正可以追踪**：保留影响结论的原判断、改变依据与新判断，不为所有输出建立编号和状态表。
- **成本匹配价值**：简单任务直接回答，复杂任务只在新增工作可能改变结论时继续。按需保存分析成果，不保存完整中间转录。
- **诚实交付**：说明实际执行方式和材料的支持范围，不代写失败的独立分析，不将模拟应用当作人物本人意见或真实用户数据。

## 来源沿革

早期版本受李继刚的圆桌讨论提示词启发。当前流程围绕任务、独立分析与交叉检查重新设计，保留求真、检验假设和接受修正的思路。此说明用于交代来源，不作为执行步骤。
