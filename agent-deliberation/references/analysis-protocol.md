# 分析与复核协议

## 分配任务

主 Agent 给每个工作 Agent 明确的交付目标、相关材料、选项与约束、任务范围，以及需要回答的问题。附上本协议路径。无需填完整状态模板，也不预写它应支持哪个结论。

- 同题独立比较：共享相同的基础材料和约束，初始分析不得看到其他答案或预期结论。
- 互补分析：只提供本任务所需背景，明确与其他任务的边界；存在依赖时说明已知结果来源，不声称该判断独立于前序分析。
- 采用特定视角时写明它需要检查的问题，不指定人格或口吻。指定思想家方法时提供可用来源，无法归属的应用标为推断。

工作 Agent 只执行被分配的分析或复核，不创建其他 Agent、不修改文件、不直接发布整体结论。需要补充材料或发现重要旁支时，将具体需求返回主 Agent。

## 返回结果

用简洁自然语言回答：

- 当前判断或发现及关键理由。
- 支持它的材料、来源或观察；区分材料本身与自己的推断。
- 会影响判断的未知条件，以及什么证据可能改变结论。

按任务需要组织，缺少内容不建立空字段。互补任务无需越过职责给全局推荐。不能编造数据、来源、用户反馈或其他 Agent 的结果，不以自评得分替代依据。

## 交叉检查

主 Agent 发送被检查的具体判断及依据原文、相关材料和一个明确的复核问题。大量条目需要区分时再使用编号。

工作 Agent 检查该问题，返回维持或修正判断的理由及依据。允许一致，不要求提出反对意见。若结论改变，说明原判断、改变依据与新判断；若现有材料无法判定，明确缺口，不重复争论。

工作 Agent 的需求和结果均经主 Agent 汇合，不直接联系其他工作 Agent。主 Agent 负责判断是否需要继续查证、补充分析或完成交付。

## 简短示例

初始任务：“根据提供的候选名和文章样本，分析名称与内容定位的匹配程度；指出主要歧义，不推测真实读者偏好。”

复核任务：“分析 A 认为该名称清楚，分析 B 认为容易被误解为情感账号。以下是双方判断与依据原文。请检查该歧义是否由材料支持，以及是否足以改变推荐。”
